# App

Здесь лежит запускаемый статический прототип.

Открытие без сервера:

```text
app/index.html
```

Основные файлы:

- `index.html` - каркас интерфейса.
- `app.js` - данные, маршрутизация, состояние, проверки, экспорт/импорт, документы, вывод и календарь.
- `styles.css` - визуальная система прототипа.
- `assets/logo.jpg` - логотип в интерфейсе.

Прототип использует `localStorage`, поэтому состояние привязано к конкретному браузеру и origin. Для переносимости используйте экспорт сессии в JSON.
